# 2D Animation Art Styles (for Full 2D Animated Explainer Videos)

When the user chooses **2D Animation** (instead of Stickman), offer them these distinct styles. If they are unsure or ask for a recommendation, recommend **Modern Flat Vector (`flat-vector`)**.

| Style Key | Style Name | Visual Feel & Reference | Best For | Recommended? |
|---|---|---|---|---|
| `flat-vector` | **Modern Flat Vector** | Bold geometric shapes, vibrant flat colours, clean vector linework or borderless flat art, expressive stylized characters (Kurzgesagt / Infographics Show aesthetic) | Science, technology, modern explainers, infographics, business, everyday concepts | **(Recommended)** |
| `storybook-cartoon`| **Classic Hand-Drawn 2D Cartoon**| Friendly cartoon proportions, expressive animated facial features, soft cel-shading, vibrant organic world, Disney/classic TV animation touch | History, storytelling, education, kids/family, warm narratives | Great for emotional stories |
| `graphic-novel` | **Cinematic Graphic Novel / Comic** | Dramatic dark ink line art, hatching/cel textures, dynamic cinematic angles, rich atmospheric shading | Mysteries, survival, thrillers, ancient warfare, dramatic history | Great for gritty topics |
| `anime-chibi` | **Stylized Chibi / Anime 2D** | Expressive anime-style characters with large eyes, dynamic comedic expressions, clean cel-shading, bright modern anime palette | Pop culture, psychology, youth explainers, energetic topics | Great for fast/fun topics |
